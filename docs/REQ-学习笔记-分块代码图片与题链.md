# 需求说明：学习笔记 · 分块 / 代码块 / 图片 / 知识点—题目联动

> **状态**：待评审 → 拆迭代  
> **关联产品**：Study Markdown Reader → **学习笔记**（`NotesWorkspace.jsx` + `quickNotes.js`，`smr-quick-notes`）  
> **背景**：当前笔记为「多页 + 单页内整段 Markdown + 一级/二级标签」；用户希望按科目**分块**书写、**快捷插入代码**、**粘贴图片**，并与**算法题 / 刷题记录**形成可追溯链接。

---

## 1. 目标与范围

### 1.1 产品目标

1. **结构化笔记**：在同一页或跨页中，能清晰区分 **数据结构 / 高数 / 概率论**（及可扩展科目）内容块，便于浏览与知识树聚合。
2. **写 DS 笔记体验**：提供**插入代码块**入口（不必手敲三个反引号），支持语言标识（如 `c`、`cpp`、`python`、`pseudo`），预览中高亮或等宽 monospace 即可。
3. **富媒体**：支持在笔记中**粘贴图片**（剪贴板 / 拖拽），生成稳定引用（本地路径或内嵌策略见下文），预览可见。
4. **知识点 ↔ 题目**：后续能把「笔记中的某一块」与「随机练习 / 二刷计划 / 错题本」中的题目或 `smr-quiz-log` 记录**弱链接**，便于复习时跳转。

### 1.2 非目标（本迭代可明确不做）

- 不做完整 Notion 式块数据库与拖拽排序全量重做（除非单独立项）。
- 不强制替换现有 Markdown 存储格式（优先**兼容现有 `body` 字符串**）。

---

## 2. 用户画像与场景

| 场景 | 行为 | 期望结果 |
|------|------|----------|
| S1 分科速记 | 打开学习笔记，想先写 DS 再写高数 | 左侧或文内有清晰「块」边界，可折叠；导出仍为可读 Markdown |
| S2 写算法 | 在 DS 块里写思路 + 代码 | 点「插入代码块」→ 选语言 → 光标落在 fenced code 内 |
| S3 贴图 | 截图后 Ctrl+V | 图片保存到约定目录，正文中插入 `![](相对或绝对路径)` 或应用支持的协议 |
| S4 题后复盘 | 刚在随机练习做错一题 | 从题目/日志「关联到笔记块」或复制链接插入笔记 |

## 3. 功能需求

### 3.1 分块笔记（按科目 / 主题）

**FR-3.1.1 块模型（建议）**

- **方案 A（推荐，改动小）**：单页 `body` 仍为 Markdown，约定**一级标题为块边界**，例如：
  - `## 📌 数据结构` … `## 📌 高数` … `## 📌 概率论`
  - 提供工具栏「插入科目块」：插入带固定前缀的二级标题 + 空行（科目从预设列表选：数据结构、高数、概率论、408-其他、自定义）。
- **方案 B（结构更强）**：`body` 拆为 `blocks: [{ id, subject, markdown }]`，保存时序列化为 Markdown 或 JSON；**迁移**旧 `body` → 单块 `default`。

**FR-3.1.2 UI**

- 编辑区可选 **「块大纲」** 侧边条：列出当前页内 `##` 标题，点击跳转滚动。
- 可选：**块折叠**（仅预览或编辑辅助层，用 `<details>` 生成需谨慎，避免破坏纯 MD 用户）。

**FR-3.1.3 与现有标签关系**

- `tagL1` / `tagL2` 表示**整页**归类；块内科目可与标签**独立**（块更细粒度）。知识树可选：按 `tagL1` 聚合 **或** 按块首标题中的科目关键字聚合（二期）。

**验收**：新建一页，插入 3 个科目块，保存重开后顺序与内容一致；`smr-quick-notes` 体积在 `MAX_BODY` 内。

---

### 3.2 插入代码块

**FR-3.2.1**

- 工具栏按钮：**「插入代码块」**。
- 弹层或下拉：语言列表（`plaintext`, `c`, `cpp`, `java`, `python`, `javascript`, `pseudo` 等）。
- 插入模板：
  ` ```lang\n\n``` `  
  并将光标置于第一行空行。

**FR-3.2.2 预览**

- 沿用现有 `marked` 渲染 fenced code；若需高亮，可选引入 `highlight.js` 或 `shiki`（**性能与包体**需评估，可二期）。

**验收**：插入后保存，切换预览，代码块等宽且换行保留。

---

### 3.3 粘贴 / 插入图片

**FR-3.3.1 Electron**

- 监听编辑器 `paste`：若 `clipboardData.files` 含图片，则：
  - 写入用户目录或工作区约定文件夹，例如 `userData/quick-notes-assets/{noteId}/` 或 Study 根下 `学习资料/笔记附件/`（需配置项）。
  - 正文插入：`![](smr-img://...)` 或现有应用已支持的本地图协议（与错题预览一致）。

**FR-3.3.2 浏览器模式**

- 降级：提示「桌面版支持粘贴保存图片」或转为 base64（**不推荐**大笔记，可限制单图大小）。

**验收**：粘贴 PNG 后预览可见；重启应用后仍可见（路径有效）。

---

### 3.4 知识点与算法题结合（题链）

**FR-3.4.1 链接形态（建议）**

- 文本协议占位，解析时高亮为可点链接，例如：
  - `[[quiz:错题本/高数错题.md#某锚点]]`
  - `[[quiz:二刷计划/2026-05-13.md#题目-3]]`
  - `[[quizlog:科目=高数&时间=2026-05-14]]`（指向练习统计或单条 log，二期）

**FR-3.4.2 从刷题页「写入笔记」**

- 在随机练习结果或错题卡片上增加「**摘录到学习笔记**」：追加到当前激活页的指定块末尾，带题源与图片链接。

**验收**：点击题链能打开对应文件（若在当前工作区）或提示路径不存在。

## 4. 非功能需求

| 项 | 说明 |
|----|------|
| 性能 | 单页 `MAX_BODY` 保持或略增；图片异步写盘，不阻塞输入 |
| 兼容 | 旧笔记无块标题时，整页视为一个「默认块」 |
| 隐私 | 图片与笔记同本地存储策略；知识库同步时需定义是否同步附件 |
| 无障碍 | 按钮带 `title`；代码块在预览中有 `pre` 语义 |

## 5. 数据与存储

- **短期**：继续 `smr-quick-notes` JSON；`body` 字符串 + 可选 `blocks` 数组（若走方案 B）。
- **附件索引**：可选 `assets: [{ id, mime, relPath, createdAt }]` 便于清理孤儿文件。
