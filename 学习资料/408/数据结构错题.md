#### 错因与辨析

（考点：**生成树与连通性**；当时疑问集中在 **为何不选 C**。）

- **生成树** \(T\) 若是 **无向图 \(G\)** 的生成树，则 \(T\) 是 \(G\) 的**生成子图**且为**树**，故必有 **\(V(T)=V(G)\)**，**\(|V(T)|=|V(G)|\)**。这里比较的是 **同一 \(G\)** 与其合法生成树，不是两个彼此独立的「图」各算一套顶点数。
- 若 **\(G\) 不连通**（例如两个连通分量），则 **不存在** 覆盖 **全部** \(V(G)\)、边均在 \(E(G)\) 内、且为**一棵树**的「\(G\) 的生成树」——标准说法是 **\(G\) 无生成树**，只有 **生成森林**（每个分量一棵生成树，**各树顶点数之和**仍等于 **\(|V(G)|\)**）。
- 容易混淆的是：「某一连通**分支**上的生成树」顶点数 = **该分支**顶点数，**小于** \(|V(G)|\)，但那是 **子图** 的生成树，**不是**「整个不连通图 \(G\) 的生成树」。
- **C 是否错误**取决于选项原文：若 C 把「**任意**图都有生成树」或「生成树顶点数与全图关系」在**不连通**情况下仍乱用上述等式，则 C **不选**；若 C 限定 **\(G\) 连通**且表述为「生成树与 \(G\) 顶点数相同」，则多为 **正确命题**。
